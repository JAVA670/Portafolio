# Studio videos — upload here

Drop the videos for **Thrulenses Studio** into this folder (MP4 or MOV). Name
them after the shoot if you can, e.g. `birthday-recap.mp4`.

On GitHub: open this folder → **Add file → Upload files** → drag the videos in
→ **Commit changes**. GitHub's web upload takes files up to 25 MB each — for
bigger films, send them another way and they'll be compressed first.

The import script turns each film into a short silent preview loop for the
site (vertical phone videos keep their real shape) and files the full cut
under `studio/public/media/videos/`.
