# Hand-Drawn Animator

A "Hand-Drawn Animator" for animated, boiling/jittery hand-drawn text. There
are two ways to use it depending on how rich you want the result.

## A) After Effects animator — full look (recommended)

`aftereffects/HandDrawnAnimator_AE.jsx` (v2) builds the complete animation in
an AE comp. It does everything Premiere scripting can't:

- **Voice sync** — import an `.srt` and the words land exactly on your speech
  (Phrase or Word-by-word). Get the SRT free from Premiere:
  **Window ▸ Text ▸ Transcribe → Create Captions → Export `.srt`** (or any
  tool). Try `assets/sample.srt` to see it instantly.
- **Real hand-drawn fonts** (auto-detects installed brush/marker fonts).
- **In/Out animation library** — Fade, Slide (4 dirs), Pop, Bounce, Scale,
  Spin, Blur, Rise, Hard — with **smooth eased keyframes** (Low/Med/High).
- **Word-by-word morph** (crossfade + scale between chunks).
- **8 styles** — Hand-Drawn, Grunge, Marker, Film, VHS, Paper, Neon, Clean.
- **Subtitle readability** — outline + drop shadow, and auto-fit so long lines
  don't overflow the frame.
- **Quick presets** — TikTok Captions, Hand-Drawn Boil, Clean Subtitle,
  Kinetic Pop set everything in one click.

Steps:
1. Install the panel: copy `HandDrawnAnimator_AE.jsx` into AE's
   `Scripts/ScriptUI Panels/` and restart AE (or run once via **File ▸ Scripts
   ▸ Run Script File…**). Enable **Preferences ▸ Scripting & Expressions ▸
   "Allow Scripts to Write Files and Access Network"**.
2. Install a hand-drawn font (the texture comes from the *font*): Permanent
   Marker, Caveat, Rock Salt, Bangers, Anton, Patrick Hand (Google Fonts).
3. Either type text, **or** tick *Import .srt* and choose your subtitle file.
   Pick a Quick Preset (or set font/style/in/out/speed yourself) and click
   **BUILD ANIMATION**.
4. It creates a finished comp. **Render it**, or **dynamic-link** the comp into
   Premiere (no MOGRT, no `importMGT`).

How the boil stays crisp while transitions stay smooth: the boil/texture
(Turbulent Displace + Roughen Edges + Posterize Time) is applied as **layer
effects**, which AE evaluates *before* the layer transform — so the text
content boils "on twos" while the Position/Scale/Opacity in-out eases
smoothly on top.

## B) Premiere panel — quick boil on a selected clip

`jsx/Premiere_Host.jsx` + the CEP panel apply a subtle hand-drawn boil +
directional in/out to a clip you've selected in Premiere, using Premiere's own
effects via the QE DOM. No After Effects. Limitations: it can't set fonts,
create text, or morph — those need route A.

1. Make a text layer in Premiere (**Type tool**), **select it**.
2. In the panel pick **Animation Speed / Style / Transition In / Out**, click
   **ANIMATE**. Use a bold/thick font — thin serifs get eaten by the boil.

> The original scripted-MOGRT route (`aftereffects/Build_Mogrt.jsx` +
> `importMGT`) is kept in the repo but is unreliable for scripted import on
> some setups — prefer route A for the rich look.

```
HandDrawnAnimator/
├── aftereffects/Build_Mogrt.jsx   PART 1 — builds & exports HandDrawnMaster.mogrt (run in AE once)
├── CSXS/manifest.xml              CEP manifest (dockable, Premiere Pro latest)
├── .debug                         remote-debug port (localhost:8088)
├── index.html                     PART 2 — panel UI
├── css/style.css                  styling (pure CSS/SVG, renders offline)
├── js/main.js                     bundles controls → JSON → evalScript
├── lib/CSInterface.js             CEP bridge (drop-in compatible with Adobe's)
├── jsx/Premiere_Host.jsx          PART 2 — host: importMGT + getMGTComponent + setValue
└── assets/HandDrawnMaster.mogrt   (generated by Build_Mogrt.jsx)
```

## How it works

1. **After Effects (once):** `Build_Mogrt.jsx` builds a 1920×1080 @ 24fps comp
   with a centered text layer, rigs the hand-drawn boil (Turbulent Displace +
   Roughen Edges + Posterize Time, animated infinitely with `time*` expressions
   — no keyframes), five toggleable style overlays (None / Grunge / Film / VHS /
   Paper), expression-driven directional in/out transitions, Responsive-Design-
   Time protected intro/outro regions, links everything to the Essential
   Graphics panel, and **exports `HandDrawnMaster.mogrt` into `/assets`.**
2. **Premiere:** the panel collects Animation Speed, Text, Fill Color, Style,
   Transition In/Out, bundles them as a **JSON object**, and `evalScript()`s
   them to `Premiere_Host.jsx`, which `importMGT()`s the MOGRT at the playhead,
   grabs `getMGTComponent()`, and writes each value with `setValue()`.

## Essential Graphics controls (built by Part 1, driven by Part 2)

| EGP control | Type | Premiere panel |
|---|---|---|
| `Source Text` | text | Text area |
| `Fill Color` | color | Hex color picker |
| `Animation Speed` | dropdown (Light/Normal/Heavy) | drives displacement amount + Posterize fps |
| `Style` | dropdown (None/Grunge/Film/VHS/Paper) | gates the 5 overlays via opacity expressions |
| `Transition In` | dropdown (Up/Down/Left/Right) | text Position expression |
| `Transition Out` | dropdown (Up/Down/Left/Right) | text Position expression |

## Setup

### Step 1 — build the MOGRT (After Effects, one time)

1. Open After Effects (2022+).
2. **File ▸ Scripts ▸ Run Script File…** → choose
   `HandDrawnAnimator/aftereffects/Build_Mogrt.jsx`.
3. It builds the comp and auto-exports `HandDrawnMaster.mogrt` into
   **`<Documents>/HandDrawnAnimator/`** (a neutral location the Premiere panel
   checks automatically, regardless of where the panel is installed). The
   final alert prints the exact saved path. (If your AE build can't
   auto-export, the alert says so and tells you where to **Export Motion
   Graphics Template…** by hand.)
   - The Premiere host searches both `<installed-extension>/assets/` **and**
     `<Documents>/HandDrawnAnimator/`, so either location works.
   - If "Apply expressions" warns about expressions being disabled, enable
     **Preferences ▸ Scripting & Expressions ▸ Allow Scripts to Write Files
     and Access Network**.

### Step 2 — enable unsigned extensions (PlayerDebugMode)

CEP refuses unsigned panels unless PlayerDebugMode is on. Premiere 2023–2025
use the CSXS 11 runtime; setting 9–12 covers every recent build.

**Windows** — run in `cmd`:
```bat
for %v in (9 10 11 12) do reg add HKCU\Software\Adobe\CSXS.%v /v PlayerDebugMode /t REG_SZ /d 1 /f
```
(Manual: `regedit` → `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` → new **String
value** `PlayerDebugMode` = `1`.)

**macOS** — run in Terminal, then restart Premiere:
```bash
for v in 9 10 11 12; do defaults write com.adobe.CSXS.$v PlayerDebugMode 1; done
killall cfprefsd
```

### Step 3 — install the panel

Copy (or symlink) the whole `HandDrawnAnimator` folder into the CEP extensions
directory:

| OS | Path (create `extensions` if missing) |
|---|---|
| Windows | `%APPDATA%\Adobe\CEP\extensions\HandDrawnAnimator` |
| macOS | `~/Library/Application Support/Adobe/CEP/extensions/HandDrawnAnimator` |

### Step 4 — run it

1. Restart Premiere → **Window ▸ Extensions ▸ Hand-Drawn Animator** (dock it
   anywhere — it's a dockable panel).
2. Open a sequence, move the playhead where you want the graphic.
3. Set Speed / Text / Color / Style / Transitions, click **ANIMATE**.
4. The MOGRT lands on the top video track at the playhead with your values.

### Debugging

With PlayerDebugMode on, the panel's Chromium inspector is at
**http://localhost:8088** (port set in `.debug`). Host errors are returned to
the panel and shown in its log area. Blank panel? Delete the CEP cache
(`%APPDATA%\Adobe\CEP\cache` / `~/Library/Caches/CSXS`) and restart.

### Distribution (optional)

For machines without PlayerDebugMode, package and sign:
```bash
ZXPSignCmd -selfSignedCert US NY "Studio" "Yeison" password cert.p12
ZXPSignCmd -sign HandDrawnAnimator HandDrawnAnimator.zxp cert.p12 password -tsa http://timestamp.digicert.com
```
Install the `.zxp` with Anastasiy's Extension Manager or `ExManCmd`.

## API & feasibility notes

- **Adding effects / building the look** happens in **After Effects**, where
  the full effect + expression engine is available — that's why the boil can
  animate infinitely with `time*` expressions and the styles can be gated by
  dropdowns. Premiere itself has **no expression engine** and **no API to
  create a text layer from scratch**, so the MOGRT is the correct vehicle.
- **`Premiere_Host.jsx`** uses only documented Premiere DOM:
  `activeSequence.importMGT(path, ticks, vTrack, aTrack)`,
  `trackItem.getMGTComponent()`, and
  `mgt.properties.getParamForDisplayName(name).setValue(value, 1)` — the
  documented equivalent of the conceptual "setParameterValue".
- **Color params** vary by build; the host tries normalized `[r,g,b,a]` (0–1)
  then falls back to 0–255.
- **Dropdown params** are 1-based, matching the AE menu order.

### Troubleshooting

- **"HandDrawnMaster.mogrt not found in /assets"** — run Part 1 in After
  Effects first.
- **"… not exposed in this MOGRT"** — an EGP control name doesn't match. The
  names the host expects are exactly: `Source Text`, `Fill Color`,
  `Animation Speed`, `Style`, `Transition In`, `Transition Out` (set in
  `Build_Mogrt.jsx`).
- **Color/transition looks off** — confirm the dropdown order in the MOGRT
  matches the UI (`STYLE_ITEMS` / `DIR_ITEMS` in `Build_Mogrt.jsx`).
