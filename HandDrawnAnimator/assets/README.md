# /assets

`HandDrawnMaster.mogrt` lives here.

It is **generated by running `../aftereffects/Build_Mogrt.jsx` in After
Effects** — that script auto-exports the .mogrt into this folder. Premiere's
`jsx/Premiere_Host.jsx` then imports it from here by path.

The file isn't committed to the repo (it's a build artifact); generate it on
your machine before using the panel.
